 Optic LED 1 Drive High=LED Off, Low=LED On — Active Low (캐소드 구동) GPIO Out U1 PB4(14) → LED1(캐소드) 1번, 애노드 N30828 → R13 510Ω/F → VCC, TP L1. FW 채널 BC·C 측정에 사용(Optic.c). 초기화 Out_PP_Low = 켜짐 상태로 시작 → 바로 뒤 Optic_Init()가 High(Off) 기록. 측정 버스트 동안만 On(약 4.2 ms, FW 주석).

Photo Sensor (PAGE1, Q1~Q3 PT11-21C-L41-TR8 ×3, 100kΩ/F 풀다운 + 22nF)
공통 입력단: 포토트랜지스터 컬렉터 = VCC, 이미터 = 측정 넷, 이미터–GND 100kΩ/F + 22nF. V = Iphoto × 100kΩ (0 ~ VCC). RC 시정수 100kΩ × 22nF = 2.2 ms → LED On 후 안정까지 대기 필요. ADC 12bit, 샘플링 384 cycles(소스 임피던스 100kΩ 대응, HW_ADC_Drive.c), 기준전압 = VDDA = VCC.

QC UART (PAGE1, USART1 PA2/PA3 Remap, TP TX/RX, 9600 8N1)
TX QC UART Transmit USART1_TX (Idle High) USART1(HW) Tx Out U1 PA2(5) → TP TX (자동넷 N14673), 직렬R·보호소자 없음. SYSCFG RMPCR1[5:4]=01로 PC3/PC2 → PA2/PA3 재배치(HW_UART_Drive.c). QC 프로그램 연결용, 지그 신호 레벨은 VCC(2.5 V) 이하여야 함.
RX QC UART Receive USART1_RX (Idle High) USART1(HW) Rx In U1 PA3(6) ← TP RX (자동넷 N14709), 외부 풀업 없음 → 지그 미연결 시 입력 부유(v2.1.1은 내부 풀업 사용, warnbox 8). RXNE 인터럽트 수신(링버퍼). Halt 전 USART1 클럭 차단.
LCD 표시 (PAGE1, LCD1 LCD_INI_12120, COM 1 + SEG 4, 직렬 1kΩ ×4)
MCU에 LCD 컨트롤러 없음(STM8L151) → GPIO로 COM/SEG 직접 구동. Lcd 모듈이 10 ms마다 COM 위상 반전, SEG는 COM과 동상 = Off, 역상 = On. 아이콘이 모두 꺼져 있어도 반전을 멈추지 않는다(멈추면 직류 인가). 대기 시 Lcd_Park()가 COM·SEG 모두 Low.

MCU 기본 / SYS (참고 — GPIO 예산 미포함, U1 STM8L151F3 TSSOP20, HSI/8 = 2 MHz)
MCU: U1 STM8L151F3_TSSOP20 (라이브러리 MW_ORCAD_LIB.OLB, 셀 STM8L151Fx_TSSOP20). Flash 8 KB / RAM 1 KB.
클럭: 외부 크리스털 없음 — HSI 16 MHz / 8 = 2 MHz (HW_CLK_Drive.c), TIM4 10 ms tick. HSE(PA2/PA3)·LSE(PC5/PC6) 핀은 각각 UART·LCD GPIO로 사용 중이므로 외부 클럭 사용 불가.
디버그: SWIM = PA0(3) → TP SM (자동넷 N13995), 외부 풀업 없음. PA0는 FW에서 재설정하지 않음(SWIM 유지).
리셋: NRST/PA1(4) → 넷 RST, R5 100kΩ → VCC 풀업, C4 100nF → GND, TP RST. 부트 핀 없음(STM8L), 부트로더 없음.
전원: J1 CR1632(3 V) → VBAT → U2 TPS7A0325PDQNR VIN(4)·EN(3) 직결(항상 On) → VOUT(1) = VCC (품번 기준 2.5 V, 데이터시트 확인 필요). U1 VDD/VDDA/VREF+(8) = VCC, C6 1µF 디커플링, VSS/VSSA/VREF−(7) = GND. ADC 기준전압 = VCC이므로 LDO 출력 정확도가 광센서 측정값에 직접 반영. TP VCC, TP GND.
Halt: HW_PWR_PrepareHalt()가 TIM4·ADC1·USART1 클럭 차단 + Ultra-Low-Power 모드, PB1 EXTI1 Falling으로 기상(HW_PWR_Drive.c 주석 기준 실측 71 µA).
