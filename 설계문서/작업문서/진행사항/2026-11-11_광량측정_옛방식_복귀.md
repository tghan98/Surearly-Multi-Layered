## 1. 수석님 참고 자료 검토 (11-11)

자료: `../작업예정/rough_files/done/2026-11-11_슈얼리 멀티 광학 비교 2/` 안의 두 HTML.
- `Opic_vs.html` (11-09): 옛 FW(`MFx_v2.1.1_alpha.2`)와 지금 FW의 측정 방법 비교
- `Optic_Solution.html` (11-11): 포화 원인 설명과 해결안 비교. A안(옛 방식, 목표 원시값 1200) 채택

### 쉬운 설명

- 센서에는 빛을 받으면 차오르는 콘덴서(물통)가 붙어 있다. τ = 100 kΩ × 22 nF = 2.2 ms.
- 지금 FW는 LED를 켜고 20 ms 뒤, 다 찬 뒤에 읽는다. 그런데 물통에 천장(포화)이 있어 빈 스틱과 발색 스틱이 둘 다 천장 근처 → 차이가 눌린다.
- 옛 방식은 차오르는 **도중에** 읽는다. 기기·채널마다 "몇 ms 뒤에 읽으면 1200인지"를 꽂을 때 맞춘다. 천장보다 한참 아래라 빛이 줄어든 만큼 값도 줄어든다.
- 원시값 자체가 지금의 게인 적용값과 같은 1200이 되므로 뒤쪽 판정(556, 시료 비율, 컷오프)은 그대로 쓸 수 있다.

우리 데이터와 맞는 점: 가운데 센서(BT·BC)는 어느 기기든 3600~3750으로 거의 같다(천장에 붙은 모양). 생산 QC에서 25 mIU 양성 4번 중 3번이 NO(`../작업예정/rough_files/2026-11-10_품질 신규FW 확인 결과/HCGM26003/`).

### 코드 대조

| 문서 내용 | 확인 |
|---|---|
| 옛 FW 목표 3000, ADC 샘플링 16 사이클 | 맞음 (`Parameter_define.h` `_nTAGET_LIGHT`, `BSP_HW_Config.c:216`). 수석님 말씀 "사이클 수 16"이 이것 |
| 지금 FW 20 ms 대기, 384 사이클 | 맞음 (`Optic.h:61`, `HW_ADC_Drive.c:34`) |
| 문서의 미확인 "ADC 읽는 동안 LED가 켜져 있나" | **켜져 있다.** `T_Scan`(Apps_MainApplication.c:1328): LED 켬 → 지연 → 가운데 센서 2번(첫 번 버림) → T → LED 끔. T가 곡선에서 조금 늦은 점을 읽는다 |
| 옛 FW 튜닝 대상 | LED마다 1번, T와 C 기준으로 2개만 맞춤(`LED_AutoTunning`:1471). 100·500 count 두 점을 직선으로 이어 3000이 되는 시간을 구함. A안은 4채널 각각 맞춤 |
| 정밀 시간용 타이머 | 지금 코드는 TIM2·TIM3를 안 쓴다 → 쓸 수 있음 |

문서가 쓰인 뒤 바뀐 것(문서 값이 낡음): 플래시 여유 60 B → **107 B**, 판정 T > 1040 / C < 1050 → **T 1080(임신)·1090(배란) / C 1005**, 스틱 빠짐 "광학 6.25 s" → 4단계에서 고침, 2600 게이트 없앰.

### 이식할 때 주의

1. **플래시.** 문서의 튜닝 초기값 식 t = −τ·ln(1 − 1200/S)는 로그 계산이라 못 넣는다. "재 보고 비율로 시간 고치기"를 2~3번 반복하는 정수 계산으로 한다. 21회 정렬 평균과 게인 계산이 빠지는 자리에 들어갈지 map으로 확인한다.
2. **시간 정밀도.** 밝은 기기는 약 0.8 ms에 1200에 닿고, 1 µs 흔들림 = 약 0.1%. 측정하는 몇 ms 동안 인터럽트를 막고 TIM2로 잰다. ADC 샘플링은 16 사이클 수준으로 짧게.
3. **방전 대기.** 매 판독 전 콘덴서를 비워야 한다: LED 끈 뒤 5τ ≈ 11 ms 이상(지금 RECOVER 10 ms). 수석님 말씀 "방전 시간 고려"가 이것.
4. **빠짐 기준 재측정.** 포화가 풀리면 발색 때 C가 지금(최저 728)보다 더 내려갈 수 있다 → `스틱빠짐_스위치+광학.md`의 C 기준은 이식 뒤에 잰다.
5. **덤프.** 게인 칸의 뜻이 충전 시간으로 바뀐다 → PC 쪽(Test_UI) 표시도 고친다.
6. 문서가 권한 사전 실험 중 E1(B안을 따로 만들어 비교)은 금요일 마감 때문에 건너뛴다. 오실로스코프가 있으면 E2(센서 전압 파형)로 포화를 눈으로 확인한다.
