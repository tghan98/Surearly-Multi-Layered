MFx_Layered 스틱 판정·이탈 확인 수정 검토

작성 2026-11-09 · hs.kim (Claude Code 보조) · 대상 MFx_Layered/User (git f11f22b + 미커밋 LCD 애니메이션 변경분, 줄 번호는 2026-11-09 작업 사본 기준) · 상태: 설계 확정, 코드 미수정 · 개정 2026-11-09: 이탈 기준 750 → 556(기존 유지), LED 전류 20mA → 0.1~0.4mA(추정) 정정

요약

  • 기상 직후 스틱 확인을 C 원시값 2600 고정 판정 → PB1 스위치 100ms 채터링 확인(10회 중 8회 이상 Low)으로 바꾼다.
  • 기상 후 C·BC·BT·T를 각 1회만 측정하고(기존 9회), 원시값 1500~3900 범위 밖이면 삽입 횟수와 관계없이 항상 BOOK 오류를 표시한다(삽입 5회 QC 구분 삭제).
  • 스틱 이탈 확인은 튜닝 게인 계산 직후부터 결과 측정까지 500ms 주기, 판정은 게인 적용 C < 556(튜닝값 1200의 46%, 기존 기준 유지 — 2026-11-09 750에서 변경). 시퀀스가 광학 측정 중일 때는 이탈 확인을 멈춘다.
  • 해결되는 문제: 고정 2600에 의한 정상 스틱 거부(A1·A3), 6.25초 이탈 확인 공백, 기상 판정의 반환값·결과 미확인(B1·B2). 실측으로 확인할 것: 스틱 없음 C가 556(초기값의 46%) 아래로 충분히 떨어지는지, 500ms로 확인 횟수가 늘어도 젖은 스틱에서 이탈 오판이 없는지.

1. 배경

  • 스틱 삽입 후 스위치(PB1)가 계속 눌린 상태를 유지해야 하나, 기구 문제로 접촉이 불안정함 → 검사 중 스틱 유무는 C 광학값으로 판정해야 함 담당자 설명.
  • 센서별 C 원시값 편차 1000~3200 담당자 설명.
  • 현재 코드 문제 코드 확인
    • 기상할 때마다 C 원시값을 고정 2600과 비교(APP_CTRL_Sequence.c:270 → APP_EXEC_Measure.c:86-87). 삽입 1회당 6번(GATE 1 + 초기 측정 5). 튜닝 하한 1500보다 높아 C의 실제 하한이 2600이 됨.
    • 검사 중 이탈 확인 주기가 6.25초(APP_DATA_Config.h:92, 기존 FW의 이중 카운터를 그대로 이식). 시료 대기부터만 확인하고, 삽입 애니메이션 중과 과다·소량·결과 측정 구간에는 확인 공백이 있음.
    • 기상 판정(원시값 2600)과 검사 중 판정(게인 적용값 556 = 튜닝값의 46%)의 기준 체계가 서로 다름.

  4. 삽입 애니메이션 시작 + 9회 측정

  5. 범위 1500~3900 확인 + 게인 계산

  7. 시료 대기부터 반응 대기까지 6.25초마다 C ≥ 556 확인

변경 후

  1. Halt → PB1 기상
  2. 100ms 채터링 확인 (10회 중 8회 이상 Low)
    실패 시 무표시 Halt
  3. 삽입 횟수 +1(기록용), 사용 횟수 초과 확인

  5. 범위 1500~3900 확인 + 게인 계산

6. 상세 설계 검토

6-1. 채터링 확인 (D1)

  • 기상 원인은 EXTI1(PB1 하강 엣지) 하나뿐 사실 (HW_PWR_PrepareHalt()에서 TIM4·ADC1·USART1 클럭 차단). 기상 후 HW_GPIO_Init()(:256)에서 PB1이 풀업 입력으로 돌아오므로 바로 읽을 수 있음.
  • 틱은 9.984ms (HW_Tick_Drive.h:8) → 10회 ≈ 100ms. 기존 SETTLE 10ms 대기는 첫 샘플 간격으로 흡수.
  • 8/10 기준: 삽입 순간 접점이 몇 번 튀어도 통과, 노이즈 펄스(수 ms)로 깨어난 경우는 대부분 High로 읽혀 실패 추정. 기구 접촉이 불안정한 실물에서 정상 삽입이 실패하는 비율을 실측해야 함.
  • 채터링 실패는 오류 표시 없이 Halt. 기록이 남지 않으므로 필요하면 실패 횟수만 EEPROM에 남김 (M15).

6-2. 이탈 확인 (D5~D7)

  • 측정 모듈은 한 번에 작업 하나만 처리(s_meas.tJob) 사실. 이탈 확인 시작이 시퀀스 측정과 겹치면 RET_BUSY.
  • D7 구현 방식: 시퀀스가 측정 단계(START_CHANNEL/CHANNEL)면 이탈 확인을 시작하지 않고, 측정이 끝난 다음 기회에 바로 확인. 결과적으로 결과 측정(4채널, 약 0.1초) 직후 1회 확인 효과가 있음.
  • 이탈 확인 측정 1회 = LED 20ms + 변환 약 5ms ≈ 25ms. 500ms 주기면 시퀀스 측정이 최대 약 25ms 늦어질 수 있으나 판정에 영향 없음 추정.
  • 이탈 확인 결과도 GetResult() == DONE일 때만 판정에 사용해야 함. ADC 실패면 이전 값으로 "있음" 유지되는 문제(B4)가 남음 → 실패 시 다음 주기 재확인 또는 광학 오류 처리 중 선택.
  • 시료 대기의 T/BT 비율 판정(1초 주기)과 이탈 확인(500ms)이 겹치므로, 스틱이 빠졌을 때 비율 판정보다 이탈 확인이 먼저 걸릴 가능성이 높아짐 → "이탈을 시료 도달로 오판"하는 경우가 줄어듦 추정.

6-3. 소모 전류 추정

LED 전류 (개정 2026-11-09): 처음에는 코드 주석(Optic.h:28, Optic.c:68/185/205)의 "20 mA"를 썼으나 회로상 불가능한 값이라 정정함. I = (VCC 2.5V − LED Vf − MCU 출력 Low 전압) / R13 510Ω → Vf = 0V라도 최대 4.9mA. LED는 FC-1608UGK-520D26(520nm 녹색, InGaN 계열로 추정, Vf가 높음)이라 2.5V 구동 시 Vf ≈ 2.3~2.4V → 약 0.1~0.4mA 추정. 실측: 측정 중 R13 양단 전압 / 510Ω.

주기LED 듀티 (25ms)평균 추가 LED 전류 (0.1~0.4mA 기준)검사 1회 (약 4분) 추가 소모
6.25초 (현재)0.4%약 0.4~1.6µA약 0.0001mAh 이하
500ms (변경)5%약 5~20µA약 0.0003~0.0013mAh

LED 전류 기준으로는 주기를 줄여도 전류 부담이 사실상 없음. 측정 중 ADC 동작 전류(데이터시트 확인 필요)는 포함하지 않았으며, 검사 중에는 MCU가 계속 동작하므로 MCU 동작 전류는 주기와 무관함.

대기(Halt) 전류 71µA(2026-10-30, 12번 기기, PPK2)에는 영향 없음. 기상 1회당 측정이 C 1회(현재)에서 0회로 줄고 PB1 읽기 10회로 바뀜.

#항목내용방법
Q1556 여유 재확인기준은 기존 556(46%) 유지로 결정(750은 위험하다고 판단해 철회). 다만 확인 횟수가 6.25초 → 500ms로 약 12배 늘어 노이즈로 한 번 기준 아래로 내려갈 기회도 늘어남. 젖은 스틱 C 최저값이 46%보다 충분히 높은지 확인기기·스틱별 반응 중 C 게인 적용값 기록 (음성·양성·고농도)

Q3범위 하한 1500센서 분포 1000~3200 중 1000~1500 기기는 항상 BOOK. 유지할지생산 기기 초기 C 분포 (QC M 덤프 StickPtr)
