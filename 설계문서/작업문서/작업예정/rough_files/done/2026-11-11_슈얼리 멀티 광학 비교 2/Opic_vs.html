Optic 측정 방법 비교 — MFx_v2.1.1_alpha.2 vs MFx_Layered

작성 2026-11-09 · 대상 HW: Surearly Multi v1.1 (OrCad-Surearly_Multi-v1.1-r1574, STM8L151F3) · 근거: 소스 코드 정적 분석 + 오브젝트 역어셈블 (실측 전) · 사실 코드·문서에서 직접 확인 / 추정 계산·해석 (실측 필요)

요약

  • 광량 정규화 원리가 다름: v2.1.1은 LED On 시간을 조절해 RC 필터 충전 도중 값을 3000에 맞추고, MFx_Layered는 20 ms 완전 안정 후 값에 디지털 게인을 곱해 1200에 맞춤.
  • 최종 결과식·판정 임계값은 동일: T = Int(Int(BTf,BTe), Int(Tf,Te)), T > 1040 양성 / C < 1050 오류. 비율 계산이라 게인은 상쇄 추정.
  • 노이즈 필터: v2.1.1 = 약 1 s 간격 5회 측정 중 가운데 3개 평균(시간축) / Layered = 4 ms 안 21회 변환 중 가운데 16개 평균(전기 노이즈만).
  • 기능 차이: Layered에는 시료 도달 판정의 BT_C 조건이 없고, 검사 중 스틱 제거 감지가 기계 스위치(즉시) 대신 광학(최대 6.25 s)임.
  • 시간 차이: v2.1.1 코드 계산상 반응 대기 약 68~84 s로 주석(165 s)·Layered(155 s)와 다름 추정 → 실측 필요.
  • 계보: MFx_Layered의 기능 원본은 MFx_New_Ver이며 v2.1.1을 이식한 것이 아님 사실 (설계서 §1 "기능 참조 원본 MFx_New_Ver", 목표광량 3000 ↔ 1200).

3-1. v2.1.1 LED On 시간 환산 추정

Debug/Obj/BSP_HW_Config.o를 IAR ielfdumpstm8 --code로 역어셈블한 BSP_SW_Delay 루프:

BSP_SW_Delay:
  JRA   0x03
  LDW   X, BSP_Dumy_Cnt     ; loop:
  DECW  X
  LDW   BSP_Dumy_Cnt, X
  LDW   X, BSP_Dumy_Cnt
  JRNE  0xF7                ; → loop
  RET
  • 루프 1회 약 9 cycles → 1 MHz에서 약 9 µs/count (STM8 명령 사이클 합산, 파이프라인 영향 미포함).
  • 튜닝 기준점: x1 = 100 count ≈ 0.9 ms (≈0.41τ → 최종값의 약 34 %), x2 = 500 count ≈ 4.5 ms (≈2.05τ → 약 87 %).
  • 즉 v2.1.1은 지수 충전 곡선 위 두 점을 직선 보간(Cal_Line_Coef, Cal_LED_Time)해 3000이 되는 On 시간을 구함. 곡선이 위로 볼록하므로 계산된 시간에서 실제 값은 목표보다 다소 높게 나옴.
  • 결과값이 C 편차(22nF 공차), HSI 클럭 오차, 코드 실행 순서(같은 점등 중 MIDL→FRNT 순으로 읽는 사이에도 충전 진행)에 직접 의존함.
센서 노드 전압의 정규화 충전 곡선 1−e−t/τ. v2.1.1은 곡선이 가파른 구간에서 읽어 시간 편차가 값 편차로 직결되고, Layered는 평탄 구간에서 읽는다. (v2.1.1 시간은 9 µs/count 추정 기준)

5-1. v2.1.1 시간 계산 근거 추정

  • 클럭: BSP_MainClock_1MHz_Config → CLK->CKDIVR = CLK_SYSCLKDiv_16 → 1 MHz.
  • TIM4: PSCR = TIM4_Prescaler_1024, ARR = 98 → 99 / (1 MHz/1024) = 101.4 ms/tick, ISR에서 g_dwTimerCnt++.
  • BSP_Delay100mSec(n): if (n < 경과tick) break → n+1 tick 도달 시 종료, 시작 위상에 따라 약 n~n+1 tick = n=4일 때 0.41~0.51 s.
  • 반응 대기 165회 → 67~84 s, 소량 시료 대기 20회 → 8~10 s. 주석("165 sec wait", "20초 대기")과 약 2배 차이.
  • MFx_Layered 주석의 "one tick is 10 ms, the same unit the old FW counted"는 MFx_New_Ver 기준이며 v2.1.1과 무관.

7. 확인 실험 제안

  1. LED 점등 시간 실측: 오실로스코프로 PB3/PB4(LED 캐소드)와 PTR1~3 파형 동시 측정 → v2.1.1 On 시간(100/500 count, 튜닝 결과값)과 읽는 시점의 충전율 확정, Layered 20 ms 안정 확인.
  2. 시퀀스 시간 실측: 두 FW에서 스틱 삽입 → 시료 도달 → 결과 표시까지 스톱워치 측정 (특히 v2.1.1 반응 대기 165회 루프).
  3. 교차 측정: 같은 기기에 두 FW를 번갈아 기록하고 같은 Lot 스틱(음성/양성/QC)으로 T·C 강도 비교, QC 명령으로 raw/게인/Empty/Finish 값 수집.
  4. 반복성: 같은 스틱 Empty 측정을 각 FW로 10회 반복 → 표준편차 비교 (노이즈 필터 효과).
