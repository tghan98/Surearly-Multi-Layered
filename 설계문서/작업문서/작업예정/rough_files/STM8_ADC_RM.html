STM8L ADC 첫 변환 오염 — RM0031·데이터시트 근거와 MFx_Layered_New 적용 검토

작성 2026-11-16 · hs.kim (Claude Code 보조) · 대상 MCU STM8L151F3 · 근거 FW/HW/rm0031-...pdf (RM0031 Rev 15), FW/HW/DS_stm8l151c2.pdf (DS7204 Rev 11) · 대상 FW FW/MFx_Layered_New, 비교 FW/MFx_v2.1.1_alpha.2 · 코드 수정 없음

요약

  • RM0031 14.3.3·14.3.4에 "ADON 후 tWKUP이 지나고 tIDLE 전에 변환을 시작해야 하며, 이전 변환 뒤 tIDLE보다 오래 지나 한 변환은 버리고 다음 값을 쓰라"는 내용이 있음 사실.
  • 조건은 "켠 뒤 첫 값은 항상 오염"이 아니라 tWKUP(3 µs) 이전 또는 tIDLE(1 s @25°C, 20 ms @70°C, 2 ms @125°C) 초과 시 첫 변환이 부정확하다는 것.
  • 구형 FW(v2.1.1)는 채널 선택마다 1회, ADON 직후 1회 더 버림 변환을 함. 신규 FW는 버림 변환이 없고, 판독 간격이 약 20~30 ms라 상온은 규격 안, 70°C에서는 tIDLE 초과.
  • 대책: 판독마다 버림 변환 1회(RM 권고, 구형 FW와 같은 원칙) 권장. Flash 약 +15~25 B 추정.

1. RM0031 Rev 15 — 14장 ADC (p.205)

14.3.3 ADC on-off control

The ADC can be powered-on by setting the ADON bit in the ADC_CR1 register. When the ADON bit is set, it wakes up the ADC from Power-down mode. Conversion should be started only when the ADC power-up time (tWKUP) has elapsed and before the ADC maximum idle delay (tIDLE) has elapsed. The software can stop conversion and put the ADC in Power-down mode by resetting the ADON bit.

→ ADON 후 tWKUP 전에 변환하면 안 되고, tIDLE가 지나기 전에 변환해야 함.

14.3.4 Single conversion mode

The time between 2 conversions must be lower than the ADC maximum idle delay (tIDLE). In case the time between 2 conversions is greater than tIDLE, the ADC must be powered-off between the 2 conversions (by clearing the ADON bit).

Another possiblity is to discard the first conversion (occuring in a time greater than tidle after previous one) and keep the next one
Before starting a conversion, the software should wait for the stabilization time (tWKUP).

→ 두 변환 사이가 tIDLE를 넘으면 ① 그 사이 ADON을 끄거나 ② 첫 변환을 버리고 다음 값을 사용.

14.3.16 Temperature sensor (참고)

After power-on, the ADC also needs a stabilization time.

3. 구형 FW (v2.1.1_alpha.2)의 처리 코드

① 채널 선택마다 1회 버림 — BSP/BSP_ADC.c:58-110 BSP_ADC_Converting_Data()

ADC1->SQR[regindex] |= tChannel;        // 채널 선택
for (5회) nop();
START → EOC 대기 → DRH/DRL 읽음          // 1회차: 버림
START → EOC 대기 → DRH/DRL 읽음          // 2회차: 반환
ADC1->SQR[regindex] &= ~tChannel;

② ADON 직후 첫 채널 1회 더 버림 — User_Apps/Apps_MainApplication.c:1328-1340, 1349-1360

BSP_ADC_Start();                         // ADON
LED 켬 → BSP_SW_Delay(LED_OnTime)
*p_BT = BSP_ADC_Converting_Data(MIDL);   // discard the first conversion
*p_BT = BSP_ADC_Converting_Data(MIDL);
  • ADON 후 수 ms 안에 변환을 연속으로 끝내고(tIDLE 문제 없음), 버림 변환까지 해서 두 겹으로 안전.

4. 신규 FW (MFx_Layered_New) 적용 검토

4-1. 현재 동작 코드

  • Optic_Start()에서 HW_ADC_Enable()(ADON), 측정 작업(1회 또는 5회 판독)이 끝나면 HW_ADC_Disable() (Optic.c:161, 237).
  • 버림 변환 없음. 주석은 "샘플링 커패시터 잔류 전하가 22 nF에 비해 1 count도 안 된다"는 이유로 Flash 절약을 위해 삭제 (Optic.c:71-75, 88). tIDLE 조건은 다루지 않음.
  • 판독 사이: OPTIC_RECOVER_TK 20 ms 후 다음 10 ms 슬롯에서 판독 → 약 20~30 ms.
