# 작업예정 — 아직 안 한 일

`진행사항/`은 날짜별로 "한 일"을 적는 곳이고, 여기는 "할 일"을 모아 두는 곳이다.

## 쓰는 법

1. 업무 지시, 대면 녹음 받아쓰기, 받은 메일·자료처럼 정리 안 된 것은 먼저 `rough_files/`에 넣는다.
2. `rough_files/`를 보고 할 일을 **하루 안에 끝내고 확인할 수 있는 크기**로 나눠 이 폴더에 파일 하나씩 만든다. 파일 이름에 날짜를 넣지 않는다.
3. 할 일 파일에는 세 가지를 적는다.
   - 출처: `rough_files/` 파일 이름과 녹음 시각 (예: `…_2.txt` 04:56~06:33)
   - 할 일
   - 끝 조건: 무엇을 확인하면 끝인지
4. 시작하는 날, 그날 `진행사항/` 문서에서 이 파일을 가리키고 결과는 진행사항에 적는다.
5. 끝나면 할 일 파일은 지운다(내용은 진행사항과 git 기록에 남는다).

이 폴더에는 늘 "아직 안 한 일"만 남는다.

## rough_files 규칙

- 받은 그대로 둔다. 내용이 틀려도(예: 녹음의 화자 표시가 바뀜) 원본은 고치지 않고, 할 일 파일에 적는다.
- 파일 이름 앞에 받은 날짜를 붙인다: `2026-11-11_이름.txt`
- 다 쓴 뒤에도 지우지 않는다. 진행사항 문서가 근거로 가리킨다.

## 목록

| 파일 | 내용 | 언제 |
|---|---|---|
| `YesNo_구분_가설.md` | 양성이 음성으로 나오는 문제 — "바닥 빛 비중" 가설 검증 | 현장 불량 기기 시험 후 |

따로 파일로 만들지 않고 `진행사항/2026-11-10_스틱판정_수정.md`에 적어 둔 대기 항목:

- 빠진 스틱의 C 여유(기준 556) — 수석님께 조정안 제안
- 전원 전압 민감도, 지그 공급 전압 측정
- 시험에 쓴 배란 기기(스틱책 3·5·6번) 배란용으로 다시 굽기
- 생산 전달용 기종별 빌드(임신/배란)
