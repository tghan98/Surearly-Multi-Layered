# 작업예정 — 아직 안 한 일

`진행사항/`은 날짜별로 "한 일"을 적는 곳이고, 여기는 "할 일"을 모아 두는 곳이다.

## 쓰는 법

1. 할 일이 생기면 여기에 파일을 만든다. 파일 이름에 날짜를 넣지 않는다.
2. 시작하는 날, 그날 `진행사항/` 문서에서 이 파일을 가리키고 결과는 진행사항에 적는다.
3. 끝나면 이 폴더에서 지운다(내용은 진행사항과 git 기록에 남는다).

이 폴더에는 늘 "아직 안 한 일"만 남는다.

## 목록

| 파일 | 내용 | 언제 |
|---|---|---|
| `YesNo_구분_가설.md` | 양성이 음성으로 나오는 문제 — "바닥 빛 비중" 가설 검증 | 현장 불량 기기 시험 후 |

따로 파일로 만들지 않고 `진행사항/2026-11-10_스틱판정_수정.md`에 적어 둔 대기 항목:

- 빠진 스틱의 C 여유(기준 556) — 수석님께 조정안 제안
- 전원 전압 민감도, 지그 공급 전압 측정
- 시험에 쓴 배란 기기(스틱책 3·5·6번) 배란용으로 다시 굽기
- 생산 전달용 기종별 빌드(임신/배란)
